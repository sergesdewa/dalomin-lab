# series

Un dossier par série, ajouté **le jour où ses épisodes passent en ligne**.

Chacun contient ce qui mérite d'exister en texte plutôt qu'à l'écran :

    topologies/   les fichiers .clab.yml
    conf/         les configurations de serveurs
    captures/     les pcap curés
    README.md     ce que la série couvre, les prérequis, les liens

La première série, consacrée à DHCP, arrive avec ses premiers épisodes.
